# Pack: Frontend

Pick at most 2 members below matching the task, most specific first; read each fully; load `references/` only when needed; otherwise follow AGENTS.md. Users may invoke any leaf directly via `/skill:<name>`.

- browser-testing-with-devtools: browser tests and UI verification

- design-system-audit: audit or build design systems

- frontend-design: build React web UI
- high-end-visual-design: premium agency-quality visual design

- minimalist-ui: minimalist visual styling

- playwright: run automated browser tests

- redesign-existing-projects: redesign existing projects
- ux-review: review user-goal, flow, state, mobile, assistive, and copy evidence
