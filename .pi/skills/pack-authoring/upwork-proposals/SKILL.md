# Upwork Proposals

## Core Principle

Answer the client's need in the first lines and prove you can start now. Energy opens; evidence closes.

## When to Use

Drafting an Upwork cover letter or proposal for one specific job post.

## When NOT to Use

Mass-applications with no job reference; inventing experience, start dates, client names, credentials, or links the user never gave.

## Workflow

1. Extract: what the client asked for, who they serve, what success looks like.
2. Select: only real, relevant experience from the user's stated history. Nothing invented.
3. Draft: opening (action + fit), evidence (job-specific), timing, training openness, sign-off.
4. Link: add a resume, portfolio, or bot URL only when the user supplied a verified one.
5. Check: every claim traces to the user's words. Unknowns become [BRACKETED PLACEHOLDER] or one focused question.

## Voice (Ryan pattern)

- Open direct: "To my future boss," or a client-specific greeting.
- Lead with action and fit: "I'm all about taking action, and this role fits how I work."
- Signal speed: quick to learn, ready to start immediately - only when true.
- Show work ethic: love to work, varied experience to help your business.
- Welcome training: "Training? Bring it on."
- Close energetic and named: "From your future VA Rockstar - [Real Name]" using the user's actual name.

## Red Flags

Any experience, start date, credential, client name, or URL not provided by the user; a proposal that could apply to any job; more than a few short paragraphs.

## Pressure Test (maintainers)

Scenario: a client needs a virtual assistant who can start Monday and handle email triage. Rubric: client need named; energy present; every claim traces to user facts; no invented link; under 150 words. Must pass twice, including one run with no details supplied, which returns placeholders or one question.
